    全屏录屏与操作指南

    1. 批量准备卡片：上传横图或竖图照片（自动完整保留不裁切），也可添加文字卡片并自由调整标题与配文。
    2. 清晰展信阶段：每张卡片抽出后会自动飞到镜头正前方，背景启动柔焦景深，文字与照片 100% 锐利停留 3 秒。

    4. 一键录屏导出：勾选「点击播放时自动进入全屏」，开启 Windows Win+G、Mac Cmd+Shift+5 或 OBS 录屏即可。
    5. Instagram 9:16 竖屏录屏：在「录屏画幅比例」中选择 Instagram 竖屏 9:16。在 2560×1600 屏幕上全屏后，中央画框为精确 900×1600（9:16），所有控制栏都会自动留在画框外侧，使用 OBS 裁剪中央 900×1600 区域即可获得零遮挡的纯净竖屏视频。
